## Стек:
- Backend: ASP.NET Core
- DB: PostgreSQL
- Cache: Redis
- Frontend: React.js
- Reverse Proxy: Nginx
- Containerization: Docker, Docker Compose

## Структура проекта:
- `/Backend` — серверная часть (REST API на ASP.NET Core)
- `/Frontend` — клиентская часть (React.js / Next.js)
- `/nginx` — конфигурация Nginx (reverse proxy)
- `docker-compose.yml` — запуск всех сервисов в контейнерах
